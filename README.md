# Timezone Override

Расширение Manifest V3 показывает сайтам выбранный часовой пояс IANA через JavaScript `Date` и `Intl`. Настройка действует постоянно для HTTP(S)-страниц и их фреймов в Chrome и Vivaldi. Расширение не использует `chrome.debugger`.

## Установка

1. Откройте `chrome://extensions` в Chrome или `vivaldi://extensions` в Vivaldi и включите режим разработчика.
2. Нажмите **Загрузить распакованное расширение** и укажите корень этого репозитория, где находится `manifest.json`.
3. Откройте **Сведения** о расширении и включите **Allow User Scripts** / **Разрешить пользовательские скрипты**. Для Chrome требуется версия 138 или новее.
4. Откройте значок расширения, найдите и выберите часовой пояс, например `America/New_York`. Выбор сразу включает подмену. Переключатель выключает или возвращает сохранённую зону.

Изменение зоны влияет на последующие вызовы API на открытых страницах. Нажмите **Перезагрузить вкладки**, чтобы сайты выполнили свой код с новой зоной с начала загрузки. Новые страницы получают подмену автоматически.

## Проверка

Для автоматических проверок нужен Node.js 22 или новее:

```sh
npm test
```

Для проверки в браузере запустите локальные страницы:

```sh
node tests/serve-smoke.mjs
```

После выбора `America/New_York` откройте `http://127.0.0.1:8765/?zone=America/New_York`: в отчёте `allPass` должно быть `true`. Повторите с `Asia/Kolkata` и соответствующим адресом. Проверяются значения, снятые до загрузки страницы, а также фрейм на другом порту. Выключите подмену и обновите страницу: `zone` должен вернуться к часовому поясу браузера. Не забудьте остановить сервер командой Ctrl+C.

Проверено 14 октября 2026 года в Chrome for Testing 154.0.8037.57 и Vivaldi 8.3.4185.3 на Windows: для обеих зон `allPass: true` в основной странице и фрейме. После выключения в обоих браузерах вернулись `Asia/Novosibirsk`, смещение `-420` минут и локальный час `19` для контрольной даты.

## Состав и ограничения

`src/background.js` хранит настройку и регистрирует раннюю инъекцию; `src/zone-math.js` и `src/timezone-shim.js` изменяют поведение `Date`/`Intl` на странице; `src/popup.*` содержит интерфейс. Автоматические тесты и локальные проверочные страницы находятся в `tests/`.

Подмена не меняет системные часы, IP-геолокацию, заголовки запросов, серверное время и Web Workers. Она не действует на внутренние страницы браузера; некоторые изолированные фреймы тоже могут быть недоступны. Уже вычисленные сайтом значения сохраняются до перезагрузки. Защита от намеренного обнаружения подмены не гарантируется.
